# Contributing to The 10-Factor Hire

The standard is shaped by the industry. Three ways to contribute, ordered by accessibility.

## 1. Web form (preferred)

The fastest path. No GitHub account, no markdown, no friction.

→ [vetano.com/the-10-factor-hire/contribute](https://vetano.com/the-10-factor-hire/contribute)

Pick a factor (or "general feedback"), write your suggestion in plain text, optionally leave your name. Submissions land in a review queue. We read all of them.

## 2. Email

Send a thought, a correction, or an objection.

→ standard@vetano.com

No format required. Long-form essays, single sentences, edge cases — all welcome.

## 3. Pull requests and issues

For developers who prefer version control. Open an issue to propose a change, or submit a PR against the relevant file.

- **Doctrine changes** — edit `STANDARD.md` or the relevant file in `/factors`.
- **Typos and copy edits** — PR directly.
- **New factors or removed factors** — open an issue first. The 10 are deliberately stable.

### PR guidelines

- One change per PR. Keep them small and reviewable.
- Doctrine is vendor-neutral. PRs that name specific platforms or products will be asked to rephrase.
- The standard binds both sides. PRs that apply a factor to only candidates or only employers will be asked to extend it both ways.

## What gets accepted

- Sharper wording.
- Edge cases the current text doesn't handle.
- Corrections to factual claims.
- Better examples of what each factor looks like in practice.

## What does not get accepted into the standard

- Implementation specifics for any particular platform or product.
- Marketing language.
- Changes that weaken bidirectionality.

Implementation notes belong in adopters' own documentation, not in the standard.

## Maintainer

[Vetano](https://vetano.com) maintains the standard. The industry shapes it.
